# Қоршаған ортаның сапасы · География 11-сынып · Интерактивті сабақ

«ЖИ мектепте: Оқытудың жаңа мүмкіндіктері» семинарына арналған ашық сабақ.
Мұғалім: Бигожаева Акмарал Тургунбаевна, «№45 ЖОББМ» ШЖҚ МКК, Астана қ.

- Оқу мақсаты: 11.3.22 — қоршаған орта сапасының көрсеткіштерін жіктеу.
- Оқулық: География 11 (ҚГБ), 89–94-б.
- Деректер: «Қазгидромет» РМК, Астана қ. бюллетеньдері (2026 ж. мамыр, 1-жартыжылдық).

## Режимдер
- Тақта: `.../geo/`
- Оқушы телефоны: `.../geo/?m=s` (QR арқылы ашылады)
- Қонақ: `.../geo/?m=g`

## Мәтінді өзгерту
Барлық мазмұн `data.js` файлында. Сабақ уақыты мен кабинетті `index.html` ішіндегі `__.__` және `№___` орындарына жазыңыз.

## Тірі рейтинг (Firebase)
`data.js` → `live.url` жолына Firebase Realtime Database мекенжайын қойыңыз.
